# ROB RUN Cheat Menu (free build)

Download: soon

A free menu-first build: 11 tabs, searchable options, pins and profiles.

## Tabs

Aim, Silent, Visual, Players, Loot, Vehicles, Cameras, Homestead, Radar, Misc, Config.

## Menu

Search filters every option, pins place up to eight controls in the top bar, theme switch (dark, contrast), keybind editor with conflict warnings, plain text profile export.

## Modules

Each tab toggles independently, the menu also works as a pure shell.

## Install

Admin loader, start ROB RUN, INSERT, F6 profiles.

## Troubleshooting

Panel unreachable: elevation missing. Pins gone: profile replaced, import export.

Windows 10/11, Steam, EAC. Keep exports outside the game folder.
